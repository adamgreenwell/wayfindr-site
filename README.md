# Wayfindr Static Site

Placeholder public site for `wayfindr.cc`.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

The static output is written to `dist/`.

## Sevalla Static Site Settings

- Root directory: `.`
- Build command: `npm ci && npm run build`
- Publish directory: `dist`
- Domain: `wayfindr.cc`
